One Node 22 server (stdlib only, no dependencies) that serves the OpenAI Chat Completions API and the Anthropic Messages API — JSON and SSE streaming — over ten simulated free-tier providers, picking the best free model for each request and failing over when a provider refuses.

## Run it

```sh
node main.ts
```
